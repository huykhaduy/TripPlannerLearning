# Course Overview

## Purpose
Create a 9-week .NET full-stack sharing course that combines foundational C#, ASP.NET Core, data access, testing, security, frontend integration, and deployment concepts.

## Intended outcome
By the end of the course, learners should be able to:
- Understand core .NET and C# fundamentals
- Build and test web APIs with ASP.NET Core
- Work with relational data and EF Core
- Apply authentication, authorization, and security basics
- Connect a frontend to backend APIs
- Package and run an application with Docker
